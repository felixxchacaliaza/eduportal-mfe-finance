# 🏛️ MFE Pensiones y Cobranzas • EduPortal Microfrontend Remoto

> **Dominio:** eduportal-mfe-finance  
> **Puerto Local:** `4207`  
> **Tecnología:** Angular 22 Zoneless + Native Federation (`@angular-architects/native-federation`)  
> **Exportación:** `./routes` vía `remoteEntry.json`  
> **Repositorio:** [https://github.com/felixxchacaliaza/eduportal-mfe-finance](https://github.com/felixxchacaliaza/eduportal-mfe-finance)  

### 🚀 Arranque Autónomo
```bash
npm install --legacy-peer-deps
npm start
```
Navega a `http://localhost:4207` para acceder al microfrontend en modo aislado.
